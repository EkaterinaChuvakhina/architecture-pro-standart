# Требования к системе банка «Стандарт»

| Код     | Требования                                                                                                                             | Комментарий |
|---------|----------------------------------------------------------------------------------------------------------------------------------------|-------------|
| **F**   | **Функциональные (Functionality)**                                                                                                     |             |
| D-F1    | Показ списка доступных депозитов с актуальными ставками на сайте для новых клиентов.                                                   |             |
| D-F2    | Подача заявки на депозит на сайте с указанием номера телефона и Ф.И.О.                                                                 |             |
| D-F3    | Отображение заявок с сайта в системе кол-центра                                                                                        |             |
| D-F4    | Показ списка доступных депозитов с актуальными и персонализированными ставками в интернет-банке.                                       |             |
| D-F5    | Подача заявки на открытие депозита в интернет-банке с указанием счета и суммы.                                                         |             |
| D-F6    | Обработка заявки на депозит менеджером бэк-офиса в AБС.                                                                                |             |
| D-F7    | Расчет ставки для клиентов интернет банка в АБС.                                                                                       |             |
| D-F8    | Уведомление клиента через СМС, после согласования условий депозита.                                                                    |             |
| D-F9    | Защита чувствительной информации при передаче.                                                                                         |             |
| D-F10   | Общий доступ к таблице ставок в АБС (депозиты + кредиты) — вместо Excel                                                                |             |
| D-F11   | Автоматический импорт ставки рефинансирования ЦБ в АБС каждый день                                                                     |             |
| C-F13   | Показ маркетингового предложения по кредиту с примерной ставкой на сайте для новых клиентов.                                           |             |
| C-F14   | Подача заявки на кредит на сайте с указанием номера телефона и Ф.И.О.                                                                  |             |
| C-F15   | Подача заявки на кредит на сайте с паспортными данными → мгновенное решение                                                            |             |
| C-F16   | Онлайн-скоринг новых клиентов только по общим данным БКИ                                                                               |             |
| C-F17   | Показ списка доступных кредитов с актуальными условиями и предодобренными предложениями в интернет-банке.                              |             |
| C-F18   | SMS-уведомление о необходимости прийти в отделение                                                                                     |             |
| C-F19   | Дедупликация заявок в АБС                                                                                                              |             |
| C-F20   | Вывод предодобренного предложения по кредиту, если к данному моменту уже произошел скоринг и была рассчитана приемлемая сумма кредита. |             |
| C-F21   | Для заявок с предодобренным предложением, проводить скоринг и приемлемую сумму кредита по упрощенной схеме.                            |             |
| D/C-F22 | Показ актуальной ставки в интернет-банке и на сайте для клиентов банка.                                                                |             |
| D/C-F23 | Форма заявления должна содержать счёт зачисления средств и данные для подачи заявки                                                    |             |
| D/C-F24 | Заявка созданная пользователем в интернет-банке отправляется в банк                                                                    |             |
| D/C-F25 | Подача заявки подтверждается СМС-кодом                                                                                                 |             |
| D/C-F26 | Информирование по СМС о смене статуса заявки.                                                                                          |             |
| **U**   | **Удобство использования (Usability)**                                                                                                 |             |
| D/C-U1  | Максимально удобный интерфейс для клиента на сайте и в интернет-банке.                                                                 |             |
| D/C-U2  | Быстрый отклик по всем операциям (миллисекунды).                                                                                       |             |
| D/C-U3  | Дизайн должен соответствовать дизайн-коду компании.                                                                                    |             |
| **R**   | **Надёжность (Reliability)**                                                                                                           |             |
| D/C-R1  | Доступность сервисов 24/7 с uptime 99,9%.                                                                                              |             |
| D-R2    | Избегать перегрузки БД АБС.                                                                                                            |             |
| D/C-R3  | Равномерное горизонтальное масштабирование и распределение запросов.                                                                   |             |
| D/C-R4  | Шифрование данных.                                                                                                                     |             |
| D/C-R5  | Переключение на резервный ЦОД                                                                                                          |             |
| D/C-R6  | Uptime интернет-банка 99,9 % (сейчас «целый день может лежать»)                                                                        |             |
| D/C-R7  | Переключение на резервный ЦОД                                                                                                          |             |
| **P**   | **Производительность (Performance)**                                                                                                   |             |
| D/C-P1  | Отклик операций в миллисекунды.                                                                                                        |             |
| D/C-P2  | Выдерживать нагрузку от онлайн-подачи заявок.                                                                                          |             |
| D/C-P3  | Выдерживать нагрузку от онлайн-подачи заявок.                                                                                          |             |
| D/C-P4  | Устранить загрузку справочников дольше 1 секунды при платежах                                                                          |             |
| C-P5    | Возможность масштабировать горизонтально Кредитный конвейер и систему кредитного скоринга, без остановки.                              |             |
| **S**   | **Поддерживаемость (Supportability)**                                                                                                  |             |
| D/C-S1  | Использовать существующие технологии в банке.                                                                                          |             |
| D/C-S2  | Обеспечить экспертизу внутри банка.                                                                                                    |             |
| D/C-S3  | Обеспечить возможность интеграции с Kafka (на перспективу).                                                                            |             |
| D/C-S4  | Разработать документацию для расширения системы.                                                                                       |             |
| D/C-S5  | Реализовать функционал силами команды банка.                                                                                           |             |
| **R**   | **Ограничения (Restrictions)**                                                                                                         |             |
| D/C-R1  | Ограничения на технологии: совместимость с существующими.                                                                              |             |
| D-R2    | Несовместимость текущего интернет-банка с Kafka.                                                                                       |             |
| D-R3    | Ограничения на масштабирование АБС (только вертикальное).                                                                              |             |
| D-R4    | Требования к MVP: обработка заявок в бэк-офисе.                                                                                        |             |
| D/C-R5  | Обязательная личная идентификация для новых клиентов в отделении банка.                                                                |             |
| C-R6    | Заявки по кредиту с предодобренным предложением должны обрабатываться в тот же рабочий день.                                           |             |
| D/C-R7  | Нет возможности ускорить процесс обмена данными между базами.                                                                          |             |
| C-R8    | Система кредитного скоринга критична, нужно следить за нагрузкой                                                                       |             |
| D-R9    | Запрет прямых SQL-запросов из интернет-банка в АБС (только через сервис-слой)                                                          |             |
